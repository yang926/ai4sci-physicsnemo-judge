# Projector identity

The display uses the existing NVIDIA horizontal logo from the pinned course,
with its original path geometry, 2560 × 1440 canvas, green eye and black wordmark
on white. It is embedded in `static/display.html`; the original style rule lives
in `static/style.css` to comply with the server's content security policy.
It needs no remote image request and no new backend asset route.

Source: [NVIDIA original SVG](https://www.nvidia.com/content/dam/en-zz/Solutions/about-nvidia/logo-and-brand/nvidia-logo-horz.svg).
The original source file's SHA256 is
`4325ea0c4078941bce84b2b1c6f045c3daf36de44cfc4c89ac5c49186f4874e8`.
The [course asset notes](../course/ETC/assets/branding/README.md) record provenance
and usage limitations. NVIDIA retains rights to its logo; the repository's
software license does not grant trademark rights. This identifies the tutorial's
technology and does not assert new sponsorship or an official NVIDIA product.

The event text follows the instructor-confirmed course schedule: AI4Science
Korea 2026, NVIDIA PhysicsNeMo Tutorial, 30 September, Seoul Dragon City.
The event name is typography, not a fabricated conference logo.

The default screen keeps a single selected Challenge and rank/name/score columns.
An explicit **Overall results** selection shows rank/name/C1-C4/total for wrap-up;
the total is emphasized and the seven-column table scrolls on narrow screens.
Both views preserve ties, automatic paging, and a visible stale-data warning.
All application-owned attendee/projector text is English, including Challenge
submission states, deadlines, finalization, connection warnings and the demo
banner. The instructor's administration pages remain Korean. Participant
nicknames are displayed as registered, including names in Korean or other scripts.
Scores and registered names
are never generated by the design. A small preview/provisional-scoring note
remains until the event rules are formally approved.

Projector presentation lives in `display.html`, `style.css`, and `app.js`.
They are outside the scoring fingerprint and read from disk per request. The
demo-only banner is added by `judge_admin/web.py`; changing that banner requires
an administrator-service restart, not a scoring-worker restart.
Deploy these files with an administrator-owned backup; do not reinitialize
the state, overwrite the course, restart workers, or change authentication.
Changes in this checkout do not mean a stopped Brev VM has been updated.

Browser tests cover ranked and empty screens at 1920 × 1080, 1366 × 768,
390 × 844, and 320 × 740, plus Challenge selection, paging, stale/recovery states,
and the read-only display boundary. Screenshot fixtures are explicitly synthetic.

## NVIDIA Sans

The scoreboard uses genuine NVIDIA Sans Version 3.000, not a look-alike or a
font-family declaration that depends on the viewer installing the font. Regular
(400), Medium (500) and Bold (700) come from NVIDIA's official brand asset CDN:

| Face | Original file | SHA256 |
| --- | --- | --- |
| Regular | [NVIDIASans_Rg.woff2](https://brand-assets.cne.ngc.nvidia.com/assets/fonts/nvidia-sans/1.0.0/NVIDIASans_Rg.woff2) | `da76017f2084c111962999f89ae2398f14db97e8689d09da3e90bdbac501c088` |
| Medium | [NVIDIASans_Md.woff2](https://brand-assets.cne.ngc.nvidia.com/assets/fonts/nvidia-sans/1.0.0/NVIDIASans_Md.woff2) | `63a4b0f9afa94218a92a9afbc09da3af6a01b713d416007cf079264794aeff3d` |
| Bold | [NVIDIASans_Bd.woff2](https://brand-assets.cne.ngc.nvidia.com/assets/fonts/nvidia-sans/1.0.0/NVIDIASans_Bd.woff2) | `e77a40c0c57903432aabc67c176e9ad9ac6768acc1883a3a14557aa2f2f8184a` |

The original font files are not modified, subsetted or converted. Their base64
transport is stored in an inert JSON element in `display.html` and decoded to
binary `FontFace` sources by `app.js`. This keeps the page self-contained without
external font requests, new backend routes or a relaxed content security policy.
The three files total 52,128 bytes (about 70 KB in base64), downloaded once per
page load, not with the five-second score polling.

Loading is independent of the scoreboard. If a browser cannot load the fonts,
system fallbacks remain and results keep updating. Pagination is recalculated
after fonts load. These faces do not contain Hangul; Korean nicknames use Apple
SD Gothic Neo on macOS, Malgun Gothic on Windows, or the browser's available
Korean fallback. The NVIDIA logo remains the original SVG, not font lettering.

Font software is excluded from Apache-2.0; the copyright notice is retained in
[NOTICE](../NOTICE). The [NVIDIA font EULA](https://raytracing-docs.nvidia.com/optix9/ext/fonts/nvidia-sans/NVIDIA_Sans_EULA_20220602_FINAL.pdf)
governs the fonts separately and limits their use to NVIDIA-related products,
services and associated materials/websites. Do not reuse the embedded payloads
as a general font package or remove their proprietary notices.
